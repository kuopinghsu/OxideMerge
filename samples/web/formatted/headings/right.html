Aurora Notes User Guide (version 2.4)

This guide covers Aurora Notes 2.4 on Windows, macOS and Linux.

Quick start #

Install the app, sign in, and your notes appear within a minute.

Install

Download the installer for your system from the downloads page and run it.

Sign in

Sign in with your email address and password, or with a passkey.

Import notes

Choose File → Import to bring in notes from Markdown files or another app.

Organizing notes #

Tags

Type # followed by a word to tag a note.

Folders

Drag a note onto a folder to move it there.

Nested folders

Folders can hold other folders, up to five levels deep.

Sync #

How often notes sync

Notes sync every 10 minutes, and right away when you close the app.

Conflicts

When a note changed on two devices, both versions are kept side by side.

Troubleshooting sync #

Sync stops

On macOS

Check the network permission

Open System Settings → Privacy & Security and allow Aurora Notes.

Where the logs are

~/Library/Logs/Aurora Notes/sync.log
